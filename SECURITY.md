# Security policy

DLA Downloader handles account credentials, network responses and files
written to user-chosen folders. Security reports are welcome.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub's private
vulnerability reporting for this repository:

https://github.com/bjose2345/dla-downloader/security/advisories/new

Include the affected version and platform, impact and reproduction steps. Never
attach real credentials, a service token or a signing key.

The project is pre-release. Security fixes target the latest source and the
newest published release.
